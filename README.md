# My Portfolio Website 🌏

This is the source code for my Portfolio Website\
The default branch is `v3.5`, which is the most current iteration.\
In case you're wondering about the `.5`, I built `v3` using svelte as I'd never used it before. Svelte was fun, and a great learning experience, however I spend a lot of time working with JSX components and really missed it, so decided to port the existing design to NextJS.\

It's good to see how far i've come since my first website 😋

You can see it live at [https://codebykieran.com](https://codebykieran.com)

## Running Locally

```bash
# install dependencies
yarn

# run the app
yarn dev
# or
npm run dev
# or
pnpm dev
# or
bun dev
```
